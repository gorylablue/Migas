# Migas — propuesta de En El Mapa

Página para Migas Comida Casual · Café (Mayagüez y Cabo Rojo).

- `index.html`: la página completa (un solo archivo).
- `/mayaguez` y `/cabo-rojo` (ver `_redirects`): la misma página con el local ya escogido. Cada perfil de Google apunta a su ruta.
- `img/`: 5 fotos de platos (recortadas de sus redes; pedir originales si cierra).
- `enelmapa-aviso.js` + formulario oculto `enelmapa-estadisticas`: aviso "¿Te gusta esta página?" y estadísticas en Netlify Forms. Abrir con `?yo=1` para no contar tus visitas.

## Ramas
- `trabajo`: avances y pruebas (publicación de rama: 0 créditos).
- `main`: producción. Solo se actualiza cuando José dice "publícalo" (15 créditos).
